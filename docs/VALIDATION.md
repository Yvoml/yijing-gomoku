# 验证记录

验证日期：2026-11-27。Node.js 24.22.1，Windows，本地 SQLite 数据库，Microsoft Edge 无界面浏览器。

## 自动化测试

执行 `node --test`，27 项通过，0 失败，约 1 秒完成。

- 规则：横、竖、双斜线与边缘长连，必胜、必防、输入棋盘不变。
- 分析：漏胜、漏防、不同难度、推荐点一致性、界面列标一致性。
- 数据：真实 SQLite 写入与服务重启恢复，跨浏览器会话隔离。
- API：坐标、占位、回合、终局、悔棋、复盘、JSON／SGF 导出与来源校验。
- 远程 Agent：本地模拟兼容接口验证工具循环、结构化回退、非法回复、超大响应、取消和密钥隐藏。
- 共享密钥：服务端密钥只能到达服务端配置的接口，访客接口覆盖不会转移密钥。
